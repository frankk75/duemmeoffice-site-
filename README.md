# DUEMME S.r.l. — sito web

Prima versione responsive del sito aziendale, pronta per GitHub Pages.

## Pubblicazione

1. Caricare nella **radice** del repository GitHub `frankk75/duemmeoffice-site-` i file `index.html`, `README.md` e la cartella `assets` (non la cartella `duemmeoffice_site` contenitore).
2. In GitHub aprire Settings > Pages, selezionare Deploy from a branch, branch `main`, cartella `/(root)`, e salvare.
3. Verificare la pubblicazione all'indirizzo `https://frankk75.github.io/duemmeoffice-site-/`.
4. Solo dopo, impostare il dominio personalizzato `www.duemmeoffice.it` in Settings > Pages e configurare i DNS Aruba in modo coerente. Non cancellare i record MX e TXT della posta elettronica.

## Da completare prima della pubblicazione ufficiale
- Confermare logo e identità visiva.
- Inserire dati societari corretti, indirizzo, telefono, email, partita IVA e PEC, ove applicabile.
- Validare elenco dei servizi e dei marchi.
- Aggiungere informazioni privacy/cookie e i relativi collegamenti se necessari.

Questo progetto contiene solo HTML, CSS e JavaScript, senza funzioni server o raccolta di dati personali.
