Catalogo e offerte

Aggiungi, modifica ed elimina modelli e offerte. Le modifiche rimangono in questa sessione finché non esporti il file e lo pubblichi nel repository GitHub.

Accesso e pubblicazione: questa pagina non è protetta da password. Chiunque conosca l'indirizzo può aprire l'editor, ma non può modificare il sito pubblico senza i permessi GitHub sul repository. Non inserire password o token qui. La pubblicazione avviene dal tuo account GitHub.

Come pubblicare

  1. Premi Esporta catalogo JSON.
  2. Apri il repository DUEMME su GitHub.
  3. Entra in assets/data/catalogo.json e usa l'icona matita per sostituire il contenuto con quello del file esportato, oppure carica il file aggiornato mantenendo lo stesso percorso.
  4. Conferma Commit changes. GitHub Pages aggiornerà i cataloghi.

L'esportazione non pubblica da sola le modifiche. Puoi importare il file JSON per continuare a lavorare in seguito.
